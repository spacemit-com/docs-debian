# 首次启动与会话

本章节介绍 Debian 首次开机后的初始化设置和用户会话，包括语言、键盘、网络、账户和登录设置。

## 开机引导（初始化设置）

如果开机后出现 GNOME 初始化向导，请按屏幕顺序完成设置。部分页面可能因镜像版本和账户状态而不显示；若直接进入登录界面，请跳到 [用户会话](#用户会话)，登录后再通过 **设置** 调整所需项目。

### 语言设置

在欢迎页面的语言列表中选择所需的显示语言，例如 **简体中文**。进入桌面后，也可以在 **设置** 中搜索 **区域与语言**，分别调整显示语言和区域格式。若系统提示注销，请保存工作后重新登录。

### 键盘布局

选择与物理键盘一致的布局。若页面提供测试输入框，可试输常用符号，确认键位是否正确，尤其是在下一步需要设置密码时。进入桌面后可在 **设置 → 键盘** 中调整输入源；配置多个输入源后，可通过顶栏的输入源指示器切换。

### 网络与时区

如果向导显示网络连接页面，可选择无线网络并输入密码，或连接有线网络。若向导允许跳过，也可以先完成初始化，进入桌面后再联网。

如果向导提供时区选项，请选择所在地对应的时区；如果没有，登录后在 **设置** 中搜索 **日期与时间**，核对系统时间和时区。区域格式与时区是两项独立设置。

### 用户信息与密码

如果向导要求创建本地账户，请按提示填写姓名、用户名和密码。姓名用于界面显示，用户名用于登录。设置密码时请核对键盘布局和大小写状态。

如果镜像已提供初始账户，请使用设备发布说明中的登录信息，并在首次登录后通过 **设置** 中的 **用户** 页面更改初始密码。若向导在首次登录后才出现，通常不需要再次创建账户。

## 完成开机引导

确认语言、键盘布局及账户信息后，按向导提示完成设置。若系统进入桌面，即可开始使用；若系统返回登录界面，请使用对应账户登录。只有在系统明确提示时才需要重启。

## 用户会话

### 登录指定用户

1. 如果登录界面列出了账户，点击要登录的账户。若界面提供 **未列出？**，也可以选择该入口并手动输入用户名。
2. 输入该账户的密码，按 `Enter` 键登录。
3. 首次登录可能需要一些时间加载桌面设置，请等待桌面显示完成。

### 选择会话

选中用户后，如果登录界面显示齿轮按钮，可以在提交密码前打开会话菜单并选择所需会话。若没有齿轮按钮，直接使用默认会话。需要更换会话时，应先注销回到登录界面，而不是仅锁屏。

如需确认当前图形会话使用的显示协议，可在桌面会话内的终端执行：

```shell
echo "$XDG_SESSION_TYPE"
```

常见输出为 `wayland` 或 `x11`。可选会话以登录界面实际显示的项目为准。

### 锁屏、注销与关机

- **锁屏**：按 `Super` + `L`。锁屏不会关闭当前应用，解锁后可继续工作。
- **注销**：保存文件，在顶栏右侧打开系统菜单，在电源或会话选项中选择 **注销**，返回登录界面。
- **重启或关机**：保存文件，在同一菜单中选择 **重新启动** 或 **关机**，并按提示确认。
